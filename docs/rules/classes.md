# Class Design Rules

## Class Size

Classes should be split into smaller classes if they exceed **120 lines**. This should only be done if it is reasonable and feasible to maintain clarity and functionality.

## File Structure

Each file should consist of a maximum of **1 class**.

## Class Organization

Structure each class as follows:

1. **Private Members**
2. **Properties**
3. **Constructor**
4. **Public Methods**
5. **Protected Methods**
6. **Private Methods**
